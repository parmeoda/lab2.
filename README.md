# LabFitnessTracker

## Project Description

This Java program calculates the monthly salary of a full-time or part-time employee. Both employee types extend the `Employee` class and override `calculateSalary()` to use their own pay formula.

## Example Output

```text
Enter employee type (full-time / part-time): full-time
Enter base pay: 4000
Enter bonus: 500
Monthly Salary: $4500.0
```

```text
Enter employee type (full-time / part-time): part-time
Enter hourly rate: 25
Enter hours worked: 80
Monthly Salary: $2000.0
```
